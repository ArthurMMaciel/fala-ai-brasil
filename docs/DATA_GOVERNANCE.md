# Governança de dados

## Princípios

- Coletar apenas o necessário e declarar finalidade.
- Classificar dados por sensibilidade e limitar acesso.
- Separar identidade, relato privado, versão compartilhável e analytics.
- Definir retenção e exclusão antes de produção.
- Registrar acesso a dados sensíveis sem copiar seu conteúdo para logs.
- Usar dados sintéticos fora de produção.
- Dados analíticos devem ser agregados e avaliados contra reidentificação.

O mapa inicial está em [data/DATA_MAP.md](data/DATA_MAP.md) e o dicionário em [data/DATA_DICTIONARY.md](data/DATA_DICTIONARY.md).
