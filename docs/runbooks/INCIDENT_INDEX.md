# Índice de runbooks

Runbooks a criar e testar antes do piloto:

1. [Plataforma indisponível](PLATFORM_DOWN.md).
2. [Banco indisponível](DATABASE_DOWN.md).
3. [Vazamento de credencial](CREDENTIAL_LEAK.md).
4. [Suspeita de acesso indevido](UNAUTHORIZED_ACCESS.md).
5. [Integração externa indisponível](EXTERNAL_INTEGRATION_DOWN.md).
6. [Erro de IA ou anonimização](AI_ERROR.md).
7. [Aumento de erros/latência](ELEVATED_ERRORS.md).
8. [Perda ou corrupção de dados](DATA_LOSS.md).

Cada runbook deve conter detecção, severidade, contenção, responsáveis, comunicação, recuperação, evidências e pós-incidente.

Os procedimentos abaixo são rascunhos de fundação e devem receber comandos, contatos e links do provedor após a infraestrutura existir.
